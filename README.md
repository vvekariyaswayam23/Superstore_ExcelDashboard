# 📊 Superstore Sales Dashboard — Excel Project

A beginner-friendly Excel project that explores Superstore sales data using cleaned data, summary calculations, and an interactive dashboard.

## ✨ Project Highlights
- 📁 Raw Data and Cleaned Data worksheets
- 🧮 Summary metrics: Total Sales, Records, Average Sale, and Average Shipping Days
- 🗂️ Sales breakdown by Category and Region
- 🎛️ Dashboard filters for Region and Category
- 📈 Charts to make sales patterns easier to understand

## 🧰 Tools Used
- Microsoft Excel

- Charts and dashboard filters

## ▶️ How to Use
1. Open the Excel workbook in Microsoft Excel.
2. Start with the **Dashboard** worksheet.
3. Use the Region and Category dropdown filters to explore the results.
4. Check the **Summary** worksheet for category and regional totals.
5. Refer to **Raw Data** and **Cleaned Data** to review the source records.
